# What the on-desk 3D object must show

Type: grilling
Status: resolved
Part of: Contest candy: spec for a shop-ready end-grain tool

## Question

What must the carpenter learn from the 3D object that the top-view face does not already say?

[Which brief bonuses belong in this spec](./04-which-brief-bonuses-belong-in-this-spec.md) put interactive 3D **in** as the object on the desk: turn it to see face, edge, and end grain. Explode / “how to glue in 3D” is later. Chrome and north star stay on [Visual north star after Noofit](./07-visual-north-star-after-noofit.md).

Answer with: required readable facts (thickness, edge species, end-grain vs face-grain, nothing else?), camera/turntable limits, and an explicit refuse list (explode, per-strip animation, photoreal wood hero shots, …).

## Answer

The 3D object exists so the carpenter sees **a thick board**, not a printed picture.

**Must be readable:**

- Finished **thickness** (the extrusion is to scale with L and W).
- **Top = end-grain face** (the gen-2 pattern).
- **Long edges** show the strip stack / species, so the side is not a copy of the top.

Nothing else. No dimensions drawn in 3D (those live on the instruction). No grain-accurate rendering required — species colour is enough.

**Camera:** drag orbit; pitch clamped about 10°–70°; no roll; a reset. Not a free fly-cam.

**Refuse:** explode, glue-up animation, per-strip flight, photoreal / HDRI hero, shadows as spectacle, a required three.js stack if CSS/canvas extrusion already shows the three facts.
