# Visual north star after Noofit

Type: grilling
Status: resolved
Part of: Contest candy: spec for a shop-ready end-grain tool

## Question

What is the visual north star for this spec, now that both references are in hand?

Evidence, not answers:

- [`ideas.md`](../../../ideas.md) already chose «Артефакт из мастерской будущего»: dark workbench, ember `#F26B38`, three-zone desk, Space Grotesk + IBM Plex Mono, physics next to the pretty face.
- [What the Noofit clothes-builder shot actually specifies](./02-what-noofit-shot-specifies.md) / [`docs/research/noofit-shot.md`](../../../docs/research/noofit-shot.md): single-screen 3D polo decorator. Steal object-first split, achromatic chrome, whole-object pattern thumbs, identity on the stage, no modal. Refuse catalog nav, jersey lettering, logo merch, S/M/L, social footer.

The contest brief is still the source of truth. A carpenter must read cuts and glue-ups, not only a pretty object.

Answer with: what we keep from `ideas.md`, what we steal from Noofit, what we refuse, and whether the current Woodcut Studio shell is close enough or must be redrawn.

## Answer

**Keep from `ideas.md`:** «Артефакт из мастерской будущего» — dark workbench, ember `#F26B38`, amber for measurements, three-zone desk (rail / stage / inspector), Space Grotesk + IBM Plex Mono, physics next to the face, no Inter / no purple dashboard.

**Steal from Noofit:** object-first split; quiet achromatic chrome; the board *is* the identity on stage; no modal for the main loop; pattern thumbs as whole boards, not swatch chips.

**Refuse:** catalog nav, jersey/logo merch chrome, S/M/L, social footer, Woodcut’s mixed-language rail, Pattern Library as a dialog, fake BUILD/COST theatre, ТОРЦЕГРАММА’s form-stack UI.

**Shell:** keep the Woodcut Studio *chassis* (three zones, type, ember). Do not redraw from a blank file and do not ship `docs/inspiration.html`. Replace the lying inspector and kill the library modal — thumbs live on the desk.
