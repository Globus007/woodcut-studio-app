# Woodcut Studio

Инструмент столяра для торцевой разделочной доски: рисуешь конструкцию, видишь лицо, получаешь раскрой и печатный лист в мастерскую. Каждый узор на экране должен быть собираемым — не сетка «нарисовать и потом придумать, как клеить».

![Демонстрация стола Woodcut Studio](docs/demo/woodcut-studio-basics.gif)

Интерфейс на русском. Размеры в миллиметрах или дюймах. Проект живёт в браузере (`localStorage`) и выгружается JSON-файлом.

## Два пути

Проект всегда идёт одним цеховым путём. Смешивать их на одном лице нельзя.

| Путь | В интерфейсе | Как строится доска |
| --- | --- | --- |
| Полосы | **Палки** | Палки клеятся в щит поколения 1, щит пилится на полосы, полосы переворачиваются торцом вверх и клеятся в поколение 2. Лицо — следствие этой последовательности. |
| Шашки | **Шашки** | На лице сетка шашек. Шашки клеятся в ряды, ряды — в доску. Сюда же фото и кисть. |

Переключение пути не «перепекает» сетку в палки. У проекта на пути шашек по-прежнему хранится полосная конструкция; возврат к палкам поднимает её снова.

## Стол

- Живое лицо сверху и объём с вращением.
- Шаблоны: полосы, шахматы, кирпич, ёлочка, плетёнка, закат, мясная лавка, акцент.
- Генератор (`G`): на палках — вариации шаблона, на шашках — вихрь, кольца, волны, рамки, терраццо, шевроны, органика.
- На шашках: кисть по породе и посадка фото на сетку.
- Размер доски, пропил, фугование, припуск по длине, выравнивание.
- Стандартные ширины шаблонов: 15, 20, 25, 30, 40 мм. Ширина мотива на полосах — толщина первого щита, не ширина палки.
- Проверки: отказ («нельзя печатать») или предупреждение. Недобор ширины или длины на полосах — такой доски ещё нет, это не отход.
- Раскрой к пиле и оценка отходов.
- Экспорт лица в SVG. Печатный лист инструкции (`/instruction`) — отдельная страница, не колонка инспектора.

Породы по умолчанию: орех, клён, вишня, ясень, падук.

## Запуск

Нужны Node.js и [pnpm](https://pnpm.io/) 11.

```bash
pnpm install
pnpm dev
```

Стол откроется на адресе, который напечатает Vite (обычно `http://localhost:5173`).

| Команда | Что делает |
| --- | --- |
| `pnpm dev` | dev-сервер Vite |
| `pnpm test` | тесты домена (Vitest) |
| `pnpm check` | `tsc --noEmit` |
| `pnpm build` | клиент в `dist/public` и Express-сервер в `dist` |
| `pnpm start` | production-сервер (`PORT`, по умолчанию 3000) |
| `pnpm format` | Prettier |

На Vercel собирается только клиент (`vite build`, каталог `dist/public`).

## Репозиторий

```
client/src/domain/     модель проекта, раскрой, шаблоны, проверки
client/src/pages/      стол (`/`) и лист (`/instruction`)
client/src/components/desk/
docs/adr/              решения: glue-first, два пути, лист, мотив, недобор
docs/research/         как торцевую доску клеят в цехе
CONTEXT.md             словарь домена
```

Язык домена — в `CONTEXT.md`. Не называйте доску canvas, путь — mode, палку — ячейкой.
