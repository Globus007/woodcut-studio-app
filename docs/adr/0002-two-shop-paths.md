# Two shop paths, not one painted grid

A project is either the strip path (glue-first: sticks, two generations, face as consequence) or the block path (blocks into courses into the board). The carpenter can import a photo onto the block path and correct it with a brush; the shop instruction then names blocks and courses, not generations. Mixing the two in one face — drawing blocks while printing a strip instruction — is the rejected ТОРЦЕГРАММА lie. ADR-0001 still holds for the strip path; this decision adds the second path instead of replacing it.
