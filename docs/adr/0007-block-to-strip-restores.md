# Block-to-strip restores the stored strip construction

A project on the block path still holds the stick list, strip map, and motif width. Switching back to the strip path puts that construction on the desk again. It does not read the painted grid as sticks — that grid is no longer one generation-1 panel, which is why ADR-0002 forbids mixing the paths on one face. The rejected alternatives are a one-way door (traps the carpenter after a photo) and unbaking the grid (the ТОРЦЕГРАММА lie).
