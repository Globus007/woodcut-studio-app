# Strip-path width shortfall is not a remainder field

Finished width and stick widths stay independent inputs. When the stick sum is short, there is no board of that width — refuse paper; do not paint a block-path remainder. When the stick sum is long, the extra is trim: warn, print, clip the finished face to the typed width from the first stick. Rejected: deriving width from the sticks, flexing sticks to fill the rectangle, and treating both signs as one leftover.
