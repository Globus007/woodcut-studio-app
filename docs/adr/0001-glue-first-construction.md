# Glue-first construction, not a species grid

A patterned end-grain board is built by milling sticks, gluing a long-grain panel, crosscutting, rotating to end grain, and gluing again. The product’s source of truth is that sequence, so every on-screen pattern is constructible and the shop instruction can name generations instead of cells. The rejected alternative is ТОРЦЕГРАММА’s grid-then-interpret model (each row its own lamella), which happily scores jewellery-box faces a strip shop cannot build.
